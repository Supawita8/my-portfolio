Role

Process

Outcome

ยกระดับการประมวลผล cognitive functions ด้วยการตอบด้วยเสียงใกล้เคียง Real-time พร้อม Dashboard สรุปผลและติดตามข้อมูลสุขภาพจิตให้แพทย์วินิจฉัยได้ทันที

↻ คลิกเพื่อดูรายละเอียด
Context

ปัญหาฝนตกขณะไม่มีคนอยู่บ้าน ทำให้ผ้าตากไว้เปียกชื้น และไม่มีระบบแจ้งเตือนหรือสลับโหมดการทำงานแบบ Real-time

Role

ผู้พัฒนาระบบควบคุมฮาร์ดแวร์และเซนเซอร์ ทำงานร่วมกับเพื่อน 2 คน

Process

พัฒนา State Machine บน Arduino เชื่อมต่อ Rain Sensor และ Servo Motor สั่งการกาง-เก็บกันสาดอัตโนมัติ พร้อมรองรับ Manual Override และส่งแจ้งเตือนผ่าน MQTT

Outcome

ระบบทำงานอัตโนมัติตอบสนองต่อฝนได้ทันทีแบบ Real-time ช่วยป้องกันผ้าเปียกชื้นได้ 90% และเพิ่มความสะดวกในการควบคุมผ่านระบบ Smart Home
